# Sales data Analysis 
This project ananlyzes sales data using Microsoft Excel amd Pivot Tables to summarize data and uncover key business insights
## Tools Used 
- Microsoft Excel
- PivotTables
  
## Data Source
- The Dataset used in this project and was sourced from kaggle for learning and data Analysis practice

 ## Key Insights
- Cash transactions generated ₦164,635 (59.8%) of total revenue, outperforming online transactions, which generated ₦110,595(40.2%).
- Sandwich was the highest revenue generating menu item with ₦65,820 while Vandapav recorded the lowest revenue at ₦20,120.
- Wednesday generated the revenue ₦48,970 whereas Friday recorded the lowest revenue ₦36,050.
-  Fastfood was the best performing product category, generating ₦188,840 more than twice the revenue of Beverages ₦86,390.
